# PR #105 ordinary-conversion review follow-up

This follow-up addresses Bill's 2026-10-04 review against the combined converter
24/world 7 implementation. It does not establish native rendering performance
or retail parity; the deferred Fiji capture campaign remains separate.

## Cache and report compatibility

Normal conversion regenerates legacy 12–23 GLBs and textures. Current-producer
reuse still requires matching source/dependency, configuration and output proof.
Metadata-only retained files keep their original producer identity. The runtime
reads its current converter schema from the shared constant.

A report with `lod_chunks` removed reproduced a deserialization failure:
`missing field lod_chunks`. Optional LOD counts, warnings and the new monotonic
LOD/publication timing fields now default when absent. Defaults in historical
reports are not measurements.

## Optional LOD and progress

`--no-lod` skips terrain compilation in both conversion routes, preserving
full-detail assets and world metadata. The flag leaves ordinary asset byte identity
unchanged. Toggle tests verify zero reconversions and unchanged retained bytes;
metadata rebuild and resumed-staging tests verify that LOD payloads/manifests and
chunk rows are absent. Enabling LOD again rebuilds generated chunks.

Previous chunk reuse remains outside this change. The opt-out provides control
without introducing another cache/provenance route. The launcher shows a bar
labeled `LOD <percent>%` during compilation, based on completed worldspaces, then
returns to the existing overall estimate. No LOD weight or ETA is fabricated;
compiling the first large world can still report zero completed worldspaces.

## Local installed-NIF census

A read-only scan covered all 93 BSA archives in the local Skyrim Special Edition
and Creation Club Data directory. It decoded every `.nif` and `.bto` entry,
checked the decoded size and Gamebryo/NetImmerse signature, and searched decoded
bytes for the block type name `BSSubIndexTriShape`.

| Entry type | Entries scanned | Entries containing the block name |
| --- | ---: | ---: |
| `.nif` | 25,433 | 0 |
| `.bto` | 1,109 | 1,109 |

Counts are archive entries, including any overridden duplicates. The final scan
had zero archive/decompression errors. It recorded archive SHA-256 identities;
local evidence is `target/pr105-bill-resolution/census/nif-block-census.json`
(SHA-256 `a1a0cef44a6f4066473ca1a8941986ecc89f7b20e4f45aed015a4f6224e6c3b5`).
The first scan omitted three archives after encountering LZ4 frame compression;
those archives were rescanned with frame decoding and are included above.

An extracted `.bto` positive control also passed the release `nif-audit`: one
`BSSubIndexTriShape`, one geometry block, no fallback blocks, and no structural
or material failures.

Absence of the block name establishes absence of that named NIF block in these
entries. It does not prove compatibility with arbitrary mods, other game versions
or different installations. Proprietary inputs and extracted positive controls
remain local.

## Operation and recovery

The [pipeline documentation](../specs/converters/pipeline.md#7-command-line-progress-interruption-and-resuming)
records same-output engine/converter exclusion, separate-output operation,
provisioned read-only sibling locks and preservation of unowned backup folders.
These safeguards remain enforced. Every conversion also exports remapped `XESP`
parents, reference header flags and enable-parent columns, including without LOD.

## Timing scope

`--report-json` now records `lod_elapsed_ms` and `publication_elapsed_ms`.
Normal publication includes runtime-pack assembly and, for replacements, old/new
generated-artifact seals, verification and the directory swap. Metadata publication
measures its new-directory rename. Ingestion-cache persistence/pruning is excluded.

Current-head full-install measurements are pending the isolated release-build run.
Earlier Fiji timings are historical and do not satisfy this measurement.
