> **Topic:** Spud `src/game`: actor values, AI packages, combat, crime, magic, quests, conditions and save state.

## Summary

- Spud’s `src/game` is a record-driven Skyrim gameplay simulation layer. It reads decoded forms and owns mutable world state.
- Size: 53 files and 29,834 lines (the original count; `src/game` holds 66 files at the pinned commit, 65 of them `.cpp` or `.hpp`), measured with `rg --files` and `wc -l` on 2026-11-13.
- Overall maturity: broad, implemented simulation code. It is not a complete Skyrim runtime; app-facing services are virtual callbacks, and tests were not found in this area.
- Its strongest coverage is AI packages, combat, crime, magic effects, condition evaluation, quests, and save state.
- The actor model includes 164 ordered actor values, modifier pools, level-up distribution, perks, and skill advancement.
- AI handles package selection, schedules, sandboxing, travel, conversation, followers, combat decisions, and flight.
- Crime tracks witnesses, faction bounties, theft, trespass, arrest, fines, jail, relationships, and stolen goods.
- Magic reads effect archetypes, targeting, casting, projectiles, impact, dispel, summon, and reanimation behavior.
- Quests parse aliases, objectives, targets, stages, story events, fragments, and serialized progress.
- Largest liberties: records often depend on host callbacks; detection is a compact visibility/sound model; many Skyrim engine systems remain outside this library.
- Mudcrab comparison: this checkout has no `src/game`. Its current SPEC excludes actor-value/effect stacking, sneak, combat, and Papyrus bindings in the first milestone.
- License note: Spud is MIT and Mudcrab is GPL-3.0-or-later. Borrow ideas and techniques, not copied code.

## Data and file formats

- Inputs are the decoded `forms::Database` form model. `src/game/CMakeLists.txt` links `spud_formats` and `spud_script`.
- The game layer reads Skyrim record signatures and fields, including `NPC_`, `RACE`, `AVIF`, `PERK`, `FACT`, `COBJ`, `SPEL`, `MGEF`, `QUST`, `SMEN`, `PACK`, `NAVM`, `SCEN`, and `LVLI`.
- `ConditionItem` preserves CTDA flags, function id, run-on mode, params, global, reference, event member, and CIS text ([`conditions.hpp:20`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/game/conditions.hpp#L20)).
- Quest, crime, and game save state use Spud binary readers/writers. Quest load rejects unknown versions ([`quests.cpp:1820`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/game/quests.cpp#L1820)). This is not evidence of native Skyrim save compatibility.
- Runtime-created potion/item forms are held in game memory and referenced by game save state ([`alchemy.cpp:73`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/game/alchemy.cpp#L73)).

## Cross-area dependencies

- Depends on `formats` for decoded forms and `script` for quest/dialogue fragments, virtual machine calls, and conditional/event data.
- `Game` coordinates Character, AI, Combat, Crime, Crafting, Magic, Items, Inventory, Perks, Quests, StoryManager, and Settings (`game.hpp`).
- AI depends on navmesh, detection, combat AI, scenes/conversations, world time, and callbacks for movement, LOS, furniture, and animation events.
- Combat and projectiles expose host interfaces for bodies, graph state, aiming, collision, water, allies, kill moves, and hit application.
- Magic depends on actor values, perks, combat, inventory/equipment, world targeting, projectile services, and settings.
- Conditions consume WorldState, forms, aliases, story event context, and optional `ConditionFacts`. Unsupported systems can return unknown/zero.
- Exposes game natives and callbacks to engine/application integration. Mudcrab has no equivalent `src/game` layer in the inspected checkout; SPEC describes a planned separation between immutable records and runtime state but excludes most gameplay behaviors from its first milestone.

## Liberties and deviations

1. **Major gameplay coverage gap — visible to player / correctness.** Mudcrab currently has no `src/game` equivalent, and its SPEC excludes core gameplay systems in the first milestone. Evidence: Mudcrab `SPEC.md:26`, `SPEC.md:66`; repository file listing contains no `src/game`.
2. **Condition fallbacks — affects gameplay correctness.** Missing runtime fact providers produce unknown/zero values. This can change quest, perk, dialogue, and spell eligibility.
