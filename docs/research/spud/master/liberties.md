> **Topic:** Where spud deliberately or accidentally departs from vanilla Skyrim.

References are file paths in the spud repository at the pinned commit. Severity is grouped by likely player impact, then gameplay correctness, then internal design. Within a group, entries appear in approximate impact order. An approximation is not necessarily a demonstrated defect. Exact vanilla differences remain unverified where stated.

## Deliberate design choices

### Visible to a player

1. **No whole-frame TAA, temporal upscaling or frame generation.** Spud uses spatial techniques and permits effect-local history. [`README.md:7`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/README.md#L7); [`docs/RENDERING.md:3`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/RENDERING.md#L3).
2. **Generated distant scenery.** Full-detail data generates far terrain, tree impostors and proxies instead of retaining the game's authored LOD path. Proxy materials remove glow, environment and tree-animation flags. [`docs/VISION.md:26`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/VISION.md#L26); [`src/importer/far/far_trees.cpp:174`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/far/far_trees.cpp#L174); [`src/importer/far/far_proxies.cpp:55`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/far/far_proxies.cpp#L55).
3. **Portal-based interior streaming.** The architecture describes viewing and streaming spaces through doorways without normal loading screens. Some crossings and propagation remain deferred. [`docs/ARCHITECTURE.md:93`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/ARCHITECTURE.md#L93).
4. **Custom grass and precipitation.** Cell-based grass placement and a precipitation occlusion volume replace original engine paths. [`src/engine/grass.cpp:189`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/grass.cpp#L189); [`src/engine/precip_occlusion.cpp:10`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/precip_occlusion.cpp#L10).
5. **Optional binaural audio.** HRTF filtering changes spatial cues, using a generic head model that may not suit every listener. [`src/audio/binaural.cpp:37`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/audio/binaural.cpp#L37); `docs/AUDIO.md`.
6. **Graphics page and menu backdrop.** A Spud-specific graphics page extends the original journal, and the backdrop uses captured constants. [`docs/UI.md:119`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/UI.md#L119); [`src/engine/backdrop.cpp:20`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/backdrop.cpp#L20).
7. **Custom cart, mount, down-camera and travel presentation.** Cart tethering, dragon leash/landing, camera fallback and travel calculations are reconstructed. Exact vanilla differences are unverified. [`src/engine/app_carts.cpp:44`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/app_carts.cpp#L44); [`src/engine/app_mount.cpp:270`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/app_mount.cpp#L270); [`src/engine/app_death.cpp:117`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/app_death.cpp#L117); [`src/engine/app_world.cpp:316`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/app_world.cpp#L316).
8. **Audio conversion.** xWMA and FUZ audio may be converted to Ogg/Vorbis, a lossy path. [`docs/formats/audio.md:10`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/formats/audio.md#L10).

### Gameplay correctness

1. **Cities merge into Tamriel.** Region tags preserve some logical identity, but worldspace structure differs from vanilla. [`docs/ARCHITECTURE.md:93`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/ARCHITECTURE.md#L93).
2. **Jolt replaces Havok.** The project explicitly does not promise identical physics behavior. [`docs/VISION.md:8`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/VISION.md#L8); `src/physics/jolt.hpp`.
3. **Papyrus tasklets execute serially.** This changes the scheduling model and may change ordering or timing. [`src/script/vm.hpp:3`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/script/vm.hpp#L3).
4. **Custom saves and translated runtime data.** Sectioned `.ost` saves are not Skyrim saves. Converted world, forms, animation and scripts can lose source semantics if import or consumers are incomplete. [`docs/formats/ost.md:1`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/formats/ost.md#L1); [`src/formats/container.hpp:20`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/container.hpp#L20).
5. **Reconstructed movement, detection and marker routing.** Movement constants, score/line-of-sight detection and first-door marker selection are approximations; exact vanilla parity is unverified. [`src/engine/movement.hpp:46`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/movement.hpp#L46); `src/game/detection.cpp`; [`src/engine/app_world.cpp:201`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/app_world.cpp#L201).
6. **Converted movies with a compatibility VM.** Original menu assets are converted, but Spud supplies the player, host services and callbacks. This is not evidence of identical menu behavior. [`docs/UI.md:3`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/UI.md#L3); [`src/ui/player/player.hpp:3`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/ui/player/player.hpp#L3); `src/ui/menu.hpp`.
7. **Audio update cadence.** Audio scheduling uses the documented 33 ms pass and some polling can take longer; event timing differences have not been measured here. `docs/AUDIO.md`; [`src/audio/sound.cpp:501`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/audio/sound.cpp#L501).
8. **Crafting tuning.** The report identifies differing documented game-setting defaults; actual effects depend on loaded settings. `src/game/crafting.cpp`.

### Internal only

1. **Native cache formats and little-endian host requirement.** Runtime data uses project-specific containers and serialized representations. [`src/formats/container.hpp:20`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/container.hpp#L20); [`src/core/binary.hpp:16`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/core/binary.hpp#L16).
2. **Version-gated caches.** Several formats reject unsupported versions; reimport may be required. Individual compatibility ranges differ. [`src/formats/osm.hpp:20`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/osm.hpp#L20); [`src/formats/osw.hpp:18`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/osw.hpp#L18).
3. **Vulkan renderer, GPU resource model and fixed pass ordering.** These replace original engine internals, with output parity unverified. `src/render/device.hpp`; [`src/render/renderer.hpp:3`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/render/renderer.hpp#L3).
4. **Developer automation and control.** Fixed-step tours, headless scripts and local control add non-vanilla tooling. [`docs/AUTOMATION.md:1`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/AUTOMATION.md#L1); [`src/engine/control.cpp:1`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/control.cpp#L1).
5. **Windows-focused implementation.** Presets and audio backend constrain current portability. [`CMakePresets.json:11`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/CMakePresets.json#L11); `src/audio/device.hpp`.

## What Mudcrab should not copy

Do not copy silent default-success behavior for missing script natives or condition facts, or discard collision-only references. Preserve diagnostics and source records. Do not assume Spud's custom save, physics, timing, movement, or generated LOD matches Skyrim. Treat optional visual and audio changes as explicit design choices, and retain Mac/Metal support.
