## Architecture

Three layers, one direction of dependency: engine rules → controller → Jolt world. Jolt never reaches the engine.

```
plugins ──convert──> .osp (shapes, bodies, layers, RANK)      .osw (LAND, refs, water, currents, primitives)
                             │                                        │
                    physics::World (sim thread)                      │
    loader threads ── prepare_cell: LAND mesh + ref bodies + primitives│
         │  queue (nearest first)                                     │
         └──> update(focus): add/remove cells, leaves, actors, impulses, one 60 Hz step
                             │                                        │
                    Jolt PhysicsSystem  <── Character (custom proxy, not a Jolt body)
                             │                    │
                    raycast/sweep/overlap   engine::Player::tick (own thread, 60 Hz, one tick ahead)
                             │                    │
                             └──── actors/projectiles/doors/UI ─────┘
```

Ownership and threading (all read from code, not docs):

- `World::update` runs on the simulation thread and is the only writer of cell bodies. `raycast_shared`, `sphere_sweep`, `sphere_overlap`, `touching_shared` and `traps_touching` may run beside it under `query_mutex` ([`world.cpp:1617-1624`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L1617-L1624), [`world.cpp:1810-1824`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L1810-L1824), [`physics.hpp:145-184`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/physics.hpp#L145-L184)). `raycast` and `sphere_cast` must not run concurrently with `update` ([`physics.hpp:154`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/physics.hpp#L154), [`:158`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/physics.hpp#L158)).
- Cell shapes are read and built on N loader threads (`loader_threads = 2`, [`world.cpp:34`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L34), [`:1041-1060`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L1041-L1060)); a loader calls `AddBodiesPrepare`, and the sim thread calls `AddBodiesFinalize` or `AddBodiesAbort` ([`world.cpp:1210-1212`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L1210-L1212), [`world.cpp:1490-1537`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L1490-L1537)).
- Model shapes are cached per mesh with a refcount ([`world.cpp:977-1039`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L977-L1039)); each cell holds model refs so unloading releases them.
- Body IDs are positional: cell i owns body i, reference r owns `cells + r`, primitives after refs, then leaves, then a reserved slot, then actors, then ragdolls ([`world.cpp:884-888`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L884-L888), [`world.cpp:1098`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L1098), [`:1153`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L1153)). Contact ordering uses that ID and the `RANK` triangle order ([`character.cpp:321-360`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/character.cpp#L321-L360)).
- The character proxy is not a Jolt body. It keeps a convex hull, does its own narrow-phase queries, its own manifold, and a port of Havok's simplex solver ([`character.cpp:17-25`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/character.cpp#L17-L25), [`simplex.hpp:1-45`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/simplex.hpp#L1-L45)). `World::update` and `Character::step` must not overlap ([`physics.hpp:123`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/physics.hpp#L123), [`:321`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/physics.hpp#L321)).
- The engine player is a separate thread with a fixed `k_tick = 1/60` ([`player.hpp:134`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/player.hpp#L134), [`player.cpp:100-118`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/player.cpp#L100-L118)), calls `world.update(feet)` then `character.step` only when `ready()` ([`player.cpp:484-491`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/player.cpp#L484-L491)).

Issues and PRs that touch this area: #464 (stair traversal bug; PR #482 merged "climb narrow stair flights with supported capsule sweeps" — matches spud's `walk_step_rise` approach), #474-#477 (collision coverage, ownership/layer policy, motion sync; PR #486 merged "attach authored collision to audited fixed containers" implements #475), #544 (open PR "match observed Skyrim jump semantics", 12 retained native jump/fall trajectories, gravity ≈926.93 units/s², launch ≈323 units/s, apex ≈71.48 units), #400 (ragdoll, named in #477), #104 (clutter phase a and hanging constraints), #90 (remember moved objects), #432/#437/#473 (authored model, playback, door activation, named in #477). #565 had not been read when this report was written, so its scope is **unverified**.

Cross-check worth flagging: spud's jump physics is consistent with #544's numbers, not with a single-gravity model. spud launches with `sqrt(2 g h)` at ground gravity (9.81 m/s² = 686.6 units/s², giving 323 units/s for h = 76) and switches to `fInAirFallingCharGravityMult` 1.35 (926.9 units/s²) as soon as the character is below its fall start ([`character.cpp:1039-1052`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/character.cpp#L1039-L1052), [`movement.cpp:336-339`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/movement.cpp#L336-L339)). #544 reports 926.93 units/s² and a 323 units/s launch. The two agree on the constants; spud's apex is 76 units because its upward phase uses the lower gravity, while #544's fixture apex is 71.48 units. Do not treat spud's apex as parity evidence; treat its gravity split and launch formula as a second implementation of the same rule.

## Port notes

- **Do not copy the controller.** [`character.cpp:403-807`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/character.cpp#L403-L807) is a reimplementation of Havok's proxy and manifold. The valuable parts are the data and the rules: contact classification thresholds, the step probe, the support-frame velocity projection, and the 95 kg/fMoveLimitMass rule. Rapier's controller already owns movement; port rules, not the solver.
- **Contact order matters to spud only.** `RANK` ([`docs/formats/osp.md:12`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/formats/osp.md#L12), [`:27`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/formats/osp.md#L27)) exists so the proxy's floating-point ties resolve like Havok. Rapier solves bodies, not a proxy plane set, so `RANK` is not worth converting for Mudcrab.
- **Layer mask is hard-coded and stale.** `default_character_layers` includes water 11 and trigger 12 ([`world.cpp:115-116`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L115-L116)), while [`physics.hpp:35-37`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/physics.hpp#L35-L37) says they are excluded. The COLL matrix import ([`rules_import.cpp:503-536`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/convert/rules_import.cpp#L503-L536)) is unused for the character. If Mudcrab copies the layer policy, derive it from data and test it (#476).
- **`broad_phase_dirty` is dead.** Docs claim a rebuild ([`MOVEMENT.md:21`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/MOVEMENT.md#L21)); code only sets and clears the flag ([`world.cpp:830-1591`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L830-L1591)). Do not cite spud as evidence that a post-stream broad-phase rebuild is implemented.
- **Motion type falls through to fixed.** [`collision_import.cpp:350-357`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/convert/collision_import.cpp#L350-L357) leaves `osp::Body::motion` at its default `fixed` for `motion_system == 7` with mass, and `prepare_cell` only tests `dynamic` ([`world.cpp:1138-1139`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L1138-L1139)). The import must record why a body is static.
- **Ragdoll budget is positional.** 4096 reserved IDs ([`world.cpp:87`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L87), [`:884-893`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L884-L893)); a dropped ragdoll logs and returns id 0 ([`world.cpp:452-456`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/physics/world.cpp#L452-L456)). Mudcrab needs an explicit failure path.
- **Two tick models.** Physics runs in `World::update` (60 Hz, sim thread), the player runs in its own 60 Hz thread one tick ahead ([`player.cpp:862-930`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/engine/player.cpp#L862-L930)). Do not mix this with Bevy's fixed schedule without deciding who owns `time`.
- **Constants worth keeping:** 0.0142875 m/unit; 69.99124 units per Havok unit; keepDistance 0.05; keepTolerance 0.1; step 31 units; shell 0.05; max 4 walls; 10 cast iterations; 20 refinement iterations; gravity 9.81 with 1.35 falling mult; ready 24 m.
- **Minimal vertical slice that proves the subsystem:** one flat 20×20 m plane, one 40 cm step, one 2 m pool with a flat water height, one 5 kg and one 200 kg dynamic cube, and a scripted 600-tick forward+jump input. Check: (1) forward speed equals the MOVT forward walk value within 1 %, (2) the step is climbed and the 60 cm block blocks, (3) submersion flips at 0.7 body height, (4) the 5 kg cube moves > 0.1 m and the 200 kg cube moves 0 and wakes, (5) the tick trace is identical across two resolutions. That covers ledger groups A, C, D and F without any game data beyond one MOVT row.

## Test ideas

Deterministic, headless, no GPU:

1. **Pure rule tests** for every `movement.cpp` function: table-driven inputs for `actor_speeds`, `requested_motion`, `fall_damage`, `jump_speed`, `applied_current`, `MoveBuffer`. These are pure maths and already separated; Mudcrab's `physics.rs` test module is the pattern.
2. **Controller conformance fixture** from `fixtures/physics/*.json`: ground plane, step bank (10-60 cm), slope fan (30-60°), overhead bars, and a 4 m ledge. Assert position/velocity/flags per tick against recorded spud traces. Extract traces with spud's `trace` command ([`MOVEMENT.md:60`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/MOVEMENT.md#L60)) if a run is possible; otherwise generate expected values from the formulas and mark them derived.
3. **Water matrix**: water height at 0.0/0.5/1.0/1.8 m over the same floor; assert `submersion`, state transitions and that no tick is spent on the bottom when depth ≥ 0.7 body.
4. **Current matrix**: linear quad, radius zone, polar quad, and a cell with no currents; assert the vector and the swimmer cap.
5. **Clutter authority test**: spawn authored masses from `CollisionBody`, apply the proxy impulse formula, assert the 95 kg cutoff and the layer scaling (projectile 0, props 3/0.1, trap 0.1).
6. **Layer-policy fixtures**: one `.glb` per layer 1,2,4,9,10,11,12,14,15,17,26,27,31,35, with a fixed body and a sensor body. Assert which become colliders, which sensors and which are rejected, and that water/trigger never become blocking geometry. This directly serves #476.
7. **Door/motion fixture**: a node-animated box collider, open/close/reverse at 60 Hz; assert the collider pose equals the node pose each step and the old pose is empty.
8. **Ragdoll fixture**: a 3-body chain with a hinge and a six-DOF joint; assert constraints hold, no body escapes, and a push moves the chain.
9. **Streaming determinism**: same input script at two frame rates and two resolutions; compare a canonical trace hash, the spud claim in [`MOVEMENT.md:30`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/MOVEMENT.md#L30).
10. **Failure tests**: missing `.osp`, zero-length capsule, unknown shape type, no free ragdoll ID, more than 16 leaves, more than 48 actors. Each must produce a counted, logged refusal, not a silent no-op. These cover the `default/no-op` column above.
