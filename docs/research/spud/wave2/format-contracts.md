## Architecture

Two halves, joined by one contract file.

```
 plugins (.esm/.esp/.esl)                     schema text (.txt, compiled in, src/importer/schema/)
        |                                                  |
        |  PluginFile: mmap, TES4 header, group tree walk   |  Schema: types, records, fields, codecs
        v                                                  v
   RawRecord[type, flags, form_id, parent, group, payload]  |
        |                                                  |
        |  compile_plugin(): per-plugin, parallel in 4096-record chunks
        |    subrecords() -> zlib + XXXX split
        |    convert_record() -> canonical field stream per schema; FormIDs written verbatim + Fixup list
        +-------------------------> PluginUnit (.unit, kind FUNT, version 1, 6 chunks)
                                        |  key = xxh64(unit version, plugin content, schema hash,
                                        |              language, 3 string-table hashes)
                                        v
                                   link_units(): load order
                                     masters -> plugin index slots -> FormID base/mask
                                     last plugin wins; deleted winner -> layered records
                                     parent/FormID resolution, sources (+groups), fixups
                                        v
                                 forms.osf (SPUD container, kind FORM, version 3, 11 chunks)
                                        |
                       forms::Database (mmap) -> find/of_type/fields/field/fixups
                                        |
                       forms::Form (forms_typed) / decode_form (forms_value) -> Value tree
```

Key properties the design buys, each verified:
- One schema text drives both writer and reader, and the text is stored in every database ([`src/formats/forms_schema.hpp:3-6`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/forms_schema.hpp#L3-L6), [`src/formats/forms.hpp:30`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/forms.hpp#L30), written at [`src/importer/records/units.cpp:619`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L619)).
- Compilation is load-order independent, linking is the only load-order step ([`src/importer/records/units.hpp:5-10`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.hpp#L5-L10)), which is what makes per-plugin caching sound.
- The container is chunk-tagged with a per-kind version, so unknown chunks are skippable ([`docs/formats/container.md:3`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/docs/formats/container.md#L3), [`src/formats/container.cpp:42-47`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/container.cpp#L42-L47)).
- The reader is mmap + open-addressed FormID index ([`src/formats/forms.cpp:115-144`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/forms.cpp#L115-L144)), so lookups are allocation-free.

Ownership and threading:
- `import_forms` (one thread) sizes jobs, then runs plugins with more than 8 MiB serially with all threads, and the rest through a `jthread` pool ([`src/importer/records/forms_import.cpp:137-161`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/forms_import.cpp#L137-L161)).
- Each `compile_plugin` splits its records into 4096-record chunks and converts chunks in parallel, writing into per-chunk buffers that are concatenated in file order ([`src/importer/records/units.cpp:186-224`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L186-L224)). Fixup indices are rebased at concatenation ([`units.cpp:207-219`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L207-L219)).
- `FileHashCache` is mutex-guarded ([`forms_import.cpp:43-52`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/forms_import.cpp#L43-L52)); `Diagnostics` is mutex-guarded ([`convert.cpp:37-44`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/convert.cpp#L37-L44)).
- `forms::Database` is immutable after construction; per-type lists and decoded records are built once under `std::call_once` ([`src/formats/forms.hpp:172-183`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/forms.hpp#L172-L183), [`forms.cpp:166-173`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/forms.cpp#L166-L173)).

Lifecycle: a unit is written to `<cache>/.import/forms/<plugin>.unit` only when `keep_units` is set ([`forms_import.cpp:127-129`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/forms_import.cpp#L127-L129)), and read back only if its stored `key` equals the recomputed key ([`forms_import.cpp:115-119`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/forms_import.cpp#L115-L119)). `forms.osf` is rewritten by `link_units` through a temp file plus rename ([`units.cpp:58-64`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L58-L64)).

## Mudcrab mapping

Design facts in Mudcrab that this topic touches:
- Two readers by explicit choice: `RecordReader::{Legacy, Inhouse}` (`crates/converter/src/config.rs:11`), default `Inhouse` (`config.rs:598-599`); schema add-ons are refused for the legacy reader (`config.rs:235-236`). #498 lists "Both reader paths" as a completion criterion.
- Schema is authored data with provenance, versioned and validated: `crates/converter/src/records/SCHEMA-FORMAT.md:1-40` (envelope `version: 1`, `sources` with revision and URL, record-level `source`, `allow_unordered` as a verified format flag, bounded plugin diagnostics that must not abort neighbouring records). `SCHEMA_BYTES` is compiled in and "changing it changes the in-house producer identity" (`records/mod.rs:32-33`).
- Format/version compatibility is checked, not assumed: `IntegrationReport.schema_version` compared with `shared::WORLD_DATABASE_SCHEMA_VERSION` (`converter/src/integration.rs:272`), per-asset-kind reuse rules in `reusable_manifest` (`converter/src/pipeline.rs:1673-1700`: nif via `can_reuse_meshes`, dds exact, pex exact or `can_reuse_scripts_and_archives`), receipt `format_version` gate (`database_cache.rs:283`), repair gate (`repair.rs:137`), runtime minimum versions in `crates/shared/src/world_assets.rs:18-19,57-72`.
- Localization is preserved as data, not resolved to text: `Value::LocalizedString(u32)` plus a `localized_bank` (`records/mod.rs:41`, `records/decoder.rs:89,313-315`).

## Port notes

Ranked by compatibility risk. Each is a defect class, not a missing feature.

1. **Silent whole-plugin skip.** `import_forms` logs and continues ([`forms_import.cpp:164-168`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/forms_import.cpp#L164-L168)); the run exits 0 ([`cmd_records.cpp:181`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/apps/skytool/cmd_records.cpp#L181)). A mod whose plugin fails one header subrecord disappears from the world with no failing status. #498's "unsupported or corrupt inputs leave the manifest incomplete" is the correct Mudcrab rule; spud does the opposite.
2. **Master-index clamp.** `resolve()` treats any master index past the list as "this plugin" ([`units.cpp:373-380`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L373-L380)). Wrong FormIDs then propagate into `parent` and every field, and `--validate` cannot see them because the ids look plausible.
3. **Raw fallback is unobservable in production.** `diag` is null unless `check` runs ([`forms_import.cpp:79`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/forms_import.cpp#L79)), yet raw fields keep master-relative FormIDs ([`convert.cpp:551-557`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/convert.cpp#L551-L557)). The count `raw_fields` is printed ([`forms_import.cpp:191`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/forms_import.cpp#L191)) but not compared with a threshold.
4. **Manual cache version.** `PluginUnit::k_version = 1` ([`units.hpp:51`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.hpp#L51)) is the only guard against reusing units compiled by older code. Nothing ties it to the converter's own revision.
5. **Cache key trusts mtime and size.** `FileHashCache` returns the stored hash without re-reading ([`forms_import.cpp:45-47`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/forms_import.cpp#L45-L47)). An editor that rewrites a plugin with the same size inside the same mtime tick keeps stale records.
6. **Zero-progress array loop** ([`convert.cpp:392-394`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/convert.cpp#L392-L394)). A schema mistake hangs the import instead of failing.
7. **Version gates are per-format and hand-written.** 20 kinds check `!=`, 6 check a range, none accepts a newer file (`rg -n "r\.version\(\)" src/formats/*.cpp`). Each new format re-implements the policy; `read_struct` silently ignores extra chunk bytes ([`container.hpp:99-103`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/container.hpp#L99-L103)), so an appended field is dropped by an older reader without a warning.
8. **Two plugin walkers** ([`plugin_file.cpp:139-191`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/plugin_file.cpp#L139-L191) vs [`importer/legacy/esm.cpp:132-190`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/legacy/esm.cpp#L132-L190)) with different resolution timing.
9. **One contract file, no schema version inside it.** The forms file carries the schema text ([`forms.cpp:53-56`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/forms.cpp#L53-L56)), so any reader can decode any field, which is the good part. The bad part: the reader has no way to say "this field's semantics changed" other than the file version (db-01).

Constants worth knowing: `k_magic = "SPUD"` ([`container.hpp:29`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/container.hpp#L29)); `k_no_string = 0xFFFFFFFF` ([`:30`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/container.hpp#L30)); 16-byte chunk alignment ([`container.cpp:27`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/container.cpp#L27), [`units.cpp:45`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L45)); unit chunk count 6 ([`units.cpp:249`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L249)); forms chunk count 11 ([`units.cpp:618`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L618)); forms version 3 ([`forms.hpp:27`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/formats/forms.hpp#L27)); unit version 1 ([`units.hpp:51`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.hpp#L51)); 4096-record compile chunks ([`units.cpp:187`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L187)); 8 MiB big-plugin split ([`forms_import.cpp:145`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/forms_import.cpp#L145)); 255 layer clamp ([`units.cpp:539`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L539)); `0xFE` full-plugin cap and `0x1000` light cap ([`units.cpp:335`](https://github.com/chasmlol/spud/blob/8c9904207a5c573a0193fb903fb5c433f127f102/src/importer/records/units.cpp#L335)).

## Test ideas

Deterministic and headless. Fixtures are synthesised, not extracted from the game, so no proprietary data is needed.

1. Container round trip: write chunks of sizes 0, 1, 15, 16, 17, 4096; assert the reader returns the same payloads, and that appending a second chunk with a duplicate id still returns the first (ctr-07).
2. Container truncation: cut the file at every length; assert `ParseError` for every cut inside a declared chunk, and document which cuts are accepted (ctr-06).
3. Version matrix test: for each of the 26 kinds, write version `k_version`, `k_version - 1`, `k_version + 1`; assert accept, accept/reject per the table, reject. This is one table-driven test and it pins the whole matrix above.
4. Chunk payload extra-bytes test: append 8 bytes to a `struct` chunk payload; assert the reader either rejects or documents the truncation (7 in port notes).
5. Schema parser: 30 small texts (duplicate type, cycle, unknown forward name, union without fallback, hex signature, quoted case value, `use` before definition). Assert the exact error line number.
6. Schema signature restriction: a record with an all-lowercase signature; assert the error message names the hex alternative (sch-02).
7. `resolve()` clamp test: a plugin whose record FormID is `0x05000001` with two masters; assert the current behaviour (index 5 -> this plugin) becomes an error after the fix (lnk-04).
8. Plugin skip accounting: a plugin with an invalid record signature; assert the run reports the skip and that the exit status reflects it (pf-14).
9. Raw fallback accounting: a CTDA with an unlisted function index; assert `raw_fields == 1`, the field bytes equal the plugin's bytes, and the diagnostic is present only in `check` (cdc-04, cmp-09).
10. Layer test: master defines a form, override deletes it, second override restores it; assert `layers`, the concatenated field stream order, and that `Form::get()` returns the last occurrence (`lnk-09`).
11. Localized string test: a localized plugin with a `STRINGS` hit, a `STRINGS` miss and a `DLSTRINGS` miss; assert empty, empty and `LOOKUP FAILED!` (`cmp-15`).
12. Cache reuse test: compile, touch the plugin's content without changing size or mtime, recompile; assert the stale unit is reused today, then assert the fix (inc-04).
13. Zero-progress array test: a schema with `element: empty` and `[]`; assert the converter returns an error instead of hanging (cmp-18). Run it under a timeout so a regression fails rather than blocks CI.
14. VMAD matrix: one fixture per property type 0-5 and 11-15 plus one unknown type; assert the byte-identical canonical output for the known types and the raw fallback for the unknown one (cdc-09).
