## Surface lighting and authored inputs

A useful correction is the attenuation comparison. The early Community Shaders reconstruction and Mudcrab’s ordinary native shader both use `1 - saturate(distance / radius)^2`. That challenges N002-L21’s `max(0, 1-d/R)^p` expression. The match is reconstruction-to-project evidence; target shader bytes and a selected draw are still needed to call either expression Skyrim’s retail behavior. The [native-lighting ledger](claims-native-lighting.json) also separates raw, vertex-shader and pixel-shader light counts, per-object selection, and scene shadow allocation. A seven-slot reconstruction or project array is not proof of a retail draw limit.

The serialized XCLL inheritance mask has no DALC flag, which supports a bounded record-layout correction. It does not determine runtime cell-versus-template precedence. Weather data declares four named color-time slots and corresponding DALC blocks. Static target notes recover affine DALC preparation and a default sunlight consumer, but not the active weather, time weights, winning source or effective draw values. These findings refine N002’s data-layout model while preserving the writer, selection and runtime gates. Ordinary reconstructed shading terms do not establish the complete selected target equation or exclude specialized skin paths.

## Image-space grading

N003’s image-space article reports 16-tap and 4-tap downsample pass families, arithmetic reduction and the coefficient vector `(0.2125, 0.7154, 0.0721)`; the coefficients match the pinned Skyrim SE 1.7.104 package. The package also supports the mapped exposure ratio, adaptation, bloom and grading operations. These results strengthen the corrected static map and challenge older N002 formula claims only where the ledger links them. N003-P07 records pass families only; N002’s disputed universal 1×1 endpoint is not attributed to this note. The historical 1.6 fit (P21) and the conclusion’s recommendation to preserve gamma-space accumulation while describing 1.6 as the best available fit (P27) are separate claims; neither establishes vanilla parity. Active pass selection, resources and per-frame parameters remain open. See the [image-space audit](imagespace-audit.md) for the claim scopes and precise N002 relations.
