# N002 native-lighting claim audit

Input: `supplied-notes.txt` SHA-256 `20589ecb5bd3892a4671143a9159ca190b701fc62850dcd87a8e545276c870a6`.

Target: SkyrimSE.exe 1.7.104.0, SHA-256 `846efccf0c1374d71f892907f46549560f2fcb0a75cb87a3eed438baa0f1402f`. The executable was not run. This audit checks 24 grouped claims against existing original-byte maps and current Mudcrab source. Current source is comparison context, never proof of retail behavior.

Assessments: 0 supported static, 12 partially supported, 0 contradicted, 12 unverified.

## Main findings

**The supplied frame sequence is not established.** The native map recovers selected call edges and branch guards, but states that it is not a complete frame sequence or timeline. It does not prove the claimed culling, light assignment, shadow generation, opaque/transparent/water composition, or postprocess order for a retail frame.

**The constant-buffer table needs two distinct identifiers.** The supplied `Slot` column mixes source parameter IDs with GPU destinations. Native input evidence shows parameter metadata entry 25 provides a byte offset that is shader-specific: for package-associated Lighting PS `00006201` and `00006601`, entry 25 is 16 floats, placing the four-float material vector at pixel `cb1[4]`. Entry 28 is 28 floats for `00006601`, placing its producer pair at `cb1[7].xy`. These values are conditional on the pinned package and selected program; they do not establish a live draw. Label metadata ID separately from stage, bound cbuffer slot, and vector/component offset.

**Seven-light and four-shadow limits remain unproved for retail.** The current Mudcrab WGSL has seven local-light entries and loops over at most seven; that is a project implementation choice. The shipped shader inventory and native call maps do not yet prove vanilla’s array capacity, CPU overflow policy, or a four-channel shared shadow texture and four-light cap.

**Equations are mostly open.** The note’s local attenuation exponent, spot cone, full sun/specular equations, ambient source precedence, and skin/hair assertions lack a complete target-bytecode-to-native-constant trace. Existing evidence does recover selected sun direction sign/transform and one RGB packing consumer, plus weather DALC row preparation. These are useful segments, not full equations or active retail values.
